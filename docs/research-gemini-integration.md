## 1. Official Python SDK

### Current SDK Package: `google-genai`
* **Official Package Name**: `google-genai`
* **Legacy Package (Deprecated)**: `google-generativeai`

> [!IMPORTANT]
> Google has transitioned to a unified SDK architecture under the package name `google-genai`. The legacy `google-generativeai` library is deprecated and should not be used for new development. The new `google-genai` package supports both the **Gemini Developer API** (Google AI Studio) and the **Gemini API on Vertex AI** through a single, consistent `Client` object.

### Installation
Install using `uv` (recommended modern Python package manager) or `pip`:

```bash
uv add google-genai
# or
pip install google-genai
```

## 2. API Key Management

The `google-genai` SDK supports both environment variable auto-detection and explicit instantiation.

### Option A: Environment Variables (Recommended)
The SDK automatically checks for the following environment variables when `genai.Client()` is initialized without arguments:
1. `GEMINI_API_KEY` (Primary)
2. `GOOGLE_API_KEY` (Fallback / Legacy)

*Note: If both are set, `GOOGLE_API_KEY` takes precedence.*

```bash
export GEMINI_API_KEY="your-api-key-here"
```

```python
from google import genai

# Client automatically reads GEMINI_API_KEY from environment
client = genai.Client()
```

### Option B: Explicit API Key (Django Settings Integration)
In Django applications using `django-environ` or `decouple`:

```python
from django.conf import settings
from google import genai

client = genai.Client(api_key=settings.GEMINI_API_KEY)
```

## 3. Basic Usage (Non-Streaming)

To send a text prompt and receive a complete response:

```python
from google import genai

client = genai.Client()

response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="Explain modern microservices in three sentences.",
)

# Extract response text
print(response.text)

# Token usage metadata
print(f"Input tokens: {response.usage_metadata.prompt_token_count}")
print(f"Output tokens: {response.usage_metadata.candidates_token_count}")
```

*Resource Management*: Clean up connection pools when done using `client.close()`.

## 4. Streaming Responses

To process and render tokens incrementally as they are generated by the model (ideal for real-time Django HTTP streaming or WebSockets):

```python
from google import genai

client = genai.Client()

response = client.models.generate_content_stream(
    model="gemini-2.5-flash",
    contents="Write a short poem about clothing design.",
)

for chunk in response:
    print(chunk.text, end="", flush=True)
```

## 5. System Instructions / Prompts

System instructions guide model persona and behavior. Set system instructions using `types.GenerateContentConfig`:

```python
from google import genai
from google.genai import types

client = genai.Client()

config = types.GenerateContentConfig(
    system_instruction="You are StyleSense AI, an expert fashion recommendation assistant. Keep responses professional, warm, and concise.",
    temperature=0.7,
)

response = client.models.generate_content(
    model="gemini-2.5-flash",
    contents="What should I wear for a formal evening gala?",
    config=config,
)

print(response.text)
```

## 6. Multi-Turn Conversation (Chat History)

The SDK provides `client.chats.create` to manage conversation state across multiple turns automatically.

### Basic Chat Session

```python
from google import genai
from google.genai import types

client = genai.Client()

# Initialize chat session with system instruction
chat = client.chats.create(
    model="gemini-2.5-flash",
    config=types.GenerateContentConfig(
        system_instruction="You are a personal shopper assistant."
    ),
)

# Turn 1
resp1 = chat.send_message("My preferred style is minimalist.")
print(resp1.text)

# Turn 2 (Context retained)
resp2 = chat.send_message("What color palette would you recommend for me?")
print(resp2.text)
```

### Initializing Chat with Pre-existing History (Stateless Web / Django Sessions)

In a stateless web application (like Django views), history can be reconstructed per request:

```python
from google import genai
from google.genai import types

client = genai.Client()

history = [
    types.Content(role="user", parts=[types.Part.from_text(text="I am looking for formal shoes.")]),
    types.Content(role="model", parts=[types.Part.from_text(text="I recommend oxfords or derby shoes in black or dark brown.")]),
]

chat = client.chats.create(
    model="gemini-2.5-flash",
    history=history,
)

response = chat.send_message("Which one is better for tuxedos?")
print(response.text)
```

## 7. Context Injection (RAG-Lite Pattern for Django)

For product recommendation backends, you can inject Django ORM catalog data directly into system instructions without requiring a vector database.

### Django Service Implementation Example

```python
import json
import logging
from typing import List, Dict, Any
from google import genai
from google.genai import types
from django.conf import settings

logger = logging.getLogger(__name__)

def generate_catalog_recommendations(user_query: str, active_products: List[Dict[str, Any]]) -> str:
    """
    RAG-Lite Context Injection Pattern for Django.
    Fetches active products from Django ORM, formats as JSON, and passes via system instructions.
    """
    catalog_json = json.dumps(active_products, indent=2)

    system_instruction = f"""You are StyleSense AI recommendation agent. 
You MUST only recommend products listed in the provided product catalog JSON below.
If no relevant product exists in the catalog, politely inform the user.

[PRODUCT CATALOG DATA]
{catalog_json}
"""

    client = genai.Client(api_key=settings.GEMINI_API_KEY)
    config = types.GenerateContentConfig(
        system_instruction=system_instruction,
        temperature=0.2, # Lower temperature for grounded factual output
    )

    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents=user_query,
        config=config,
    )

    return response.text
```

## 8. Error Handling & Rate Limits

The SDK defines exceptions under the `google.genai.errors` module.

### Exception Hierarchy
* **`errors.APIError`**: Base class for service errors (contains `e.code` and `e.message`).
* **`errors.ClientError`**: 4xx series errors (e.g. 400 Bad Request, 403 Forbidden, 429 Rate Limit Exceeded).
* **`errors.ServerError`**: 5xx series errors (e.g. 500 Internal Server Error, 503 Service Unavailable).

### Production Catch & Retry Pattern

```python
import logging
from google import genai
from google.genai import errors

logger = logging.getLogger(__name__)
client = genai.Client()

try:
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents="Hello Gemini",
    )
    print(response.text)

except errors.APIError as e:
    if e.code == 429:
        logger.warning("Gemini API rate limit / quota exceeded (HTTP 429). Implement exponential backoff.")
    elif e.code == 403:
        logger.error("Gemini API key is invalid or permissions denied (HTTP 403).")
    else:
        logger.error(f"Gemini API error [{e.code}]: {e.message}")
except Exception as e:
    logger.exception("Unexpected error communicating with Gemini API.")
```

## 9. Free Tier Rate Limits

Google AI Studio Free Tier limits apply at the **Google Cloud Project level** (shared across all keys in that project):

| Metric | Free Tier Quota (Gemini 2.5 Flash / 2.0 Flash) |
| :--- | :--- |
| **RPM** (Requests Per Minute) | **15 RPM** |
| **TPM** (Tokens Per Minute) | **1,000,000 TPM** |
| **RPD** (Requests Per Day) | **1,500 RPD** |

> [!NOTE]
> Free Tier quotas reset daily at midnight Pacific Time. For production web applications with multiple concurrent users, upgrade to the pay-as-you-go tier in Google AI Studio to increase RPM/RPD limits.

## 10. Asynchronous Support (`client.aio`)

The `google-genai` SDK provides non-blocking asynchronous APIs via `client.aio`. This is critical for Django ASGI applications, async views (`async def my_view(request):`), and background task runners (Celery / Django Channels).

### Async Non-Streaming
```python
import asyncio
from google import genai

async def fetch_recommendation():
    client = genai.Client()
    response = await client.aio.models.generate_content(
        model="gemini-2.5-flash",
        contents="Give 3 quick summer styling tips.",
    )
    print(response.text)

asyncio.run(fetch_recommendation())
```

### Async Streaming in Django ASGI View
```python
from google import genai
from django.http import StreamingHttpResponse

async def stream_ai_chat_view(request):
    user_query = request.GET.get("q", "Hello")
    client = genai.Client()

    async def event_stream():
        response = await client.aio.models.generate_content_stream(
            model="gemini-2.5-flash",
            contents=user_query,
        )
        async for chunk in response:
            yield chunk.text

    return StreamingHttpResponse(event_stream(), content_type="text/plain")
```

### Async Chat Session
```python
from google import genai

async def run_async_chat():
    client = genai.Client()
    chat = client.aio.chats.create(model="gemini-2.5-flash")
    
    res1 = await chat.send_message("I like minimalist jackets.")
    res2 = await chat.send_message("What color should I pick?")
    print(res2.text)
```
