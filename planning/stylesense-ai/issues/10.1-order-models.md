# 10.1 — Order Models

**What to build:** A new `apps.orders` holding placed orders. `Order` freezes the money (`subtotal`/`discount`/`shipping`/`total`) and `OrderItem` freezes the line — both the price paid and the list price it was marked down from. This is the other half of 8.1's decision that `CartItem` stores no price: the bag tracks live catalog pricing, the order must keep billing what it billed. `OrderItem.product` is `SET_NULL` and carries a snapshot of the product's name, brand, slug, and image, so a delisted or deleted product empties the link without breaking order history.

**Blocked by:** 08 — Shopping Cart

**Status:** done

- [x] `apps/orders` scaffolded, registered in `INSTALLED_APPS`
- [x] `Order` — user FK, unique `order_number`, `status`, four frozen money columns, `payment_reference`, `placed_at`/`updated_at`
- [x] `Order.Status` — `pending`/`processing`/`shipped`/`delivered`/`cancelled`/`failed`; `Order.LIFECYCLE` names only the forward path (`processing → shipped → delivered`), so the terminal states can never be advanced into
- [x] `generate_order_number()` — `SS-YYYYMMDD-XXXX` with a 4-char ambiguity-free alphabet (no `I`/`O`/`0`/`1`). Random, not sequential: the pk already counts orders, and a customer-facing reference shouldn't leak how many the shop has taken
- [x] `Order.item_count` is a derived property, not a column — a stored count could drift from the lines
- [x] `OrderItem` — `SET_NULL` product FK + `product_name`/`product_brand`/`product_slug`/`image_url` snapshot, `size`, `color`, `quantity`, `list_price` **and** `unit_price` (so an order can show what was saved, not just what was paid)
- [x] `CheckConstraint(quantity >= 1)` → `orderitem_quantity_positive`
- [x] `Index(user, -placed_at)` → `order_user_recent_idx` — the single query the history page makes
- [x] Admin: `OrderAdmin` with a fully read-only `OrderItemInline` (no add, no delete) — lines are a completed transaction, and editing them would desync them from the order's frozen totals
- [x] Migration `orders/0001_initial` applied
