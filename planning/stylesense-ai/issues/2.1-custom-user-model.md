# 2.1 — Custom User Model (AbstractBaseUser)

**What to build:** Email-based custom User model with full control via AbstractBaseUser + custom manager.

**Blocked by:** 01 — Project Skeleton & Core Architecture

**Status:** ready

## Deliverables
- [ ] Create `apps/users/` Django app
- [ ] Custom User model extending `AbstractBaseUser` + `PermissionsMixin`
  - Fields: `email` (unique, primary login), `first_name`, `last_name`, `style_preferences` (JSONField), `is_active`, `is_staff`, `date_joined`
  - `USERNAME_FIELD = 'email'`
  - No `username` field
- [ ] Custom `UserManager` with `create_user()` and `create_superuser()`
- [ ] `AUTH_USER_MODEL = 'users.User'` in settings
- [ ] Run `makemigrations` + `migrate`
- [ ] Verify: create superuser via `createsuperuser`, log into admin

## Key Decisions
- AbstractBaseUser for full control (interview story: "I extended AbstractBaseUser, not AbstractUser")
- Email as the sole login identifier
- `style_preferences` as JSONField (for AI personalization later)
