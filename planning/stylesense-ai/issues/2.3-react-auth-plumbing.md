# 2.3 — React Auth Plumbing (Axios, AuthContext, ProtectedRoute, Router)

**What to build:** Frontend auth infrastructure — Axios instance with cookie support, AuthContext for state, ProtectedRoute wrapper, and React Router v7 setup.

**Blocked by:** 2.2 — JWT Auth Endpoints

**Status:** ready

## Deliverables
- [ ] Install `react-router` (v7), `axios`
- [ ] Create Axios instance (`src/api/axios.ts`)
  - `baseURL` pointing to backend
  - `withCredentials: true` (sends cookies)
  - Response interceptor: on 401, attempt token refresh, retry original request
- [ ] Create auth API module (`src/api/auth.ts`)
  - `register(email, password)`
  - `login(email, password)`
  - `logout()`
  - `getMe()` — calls `/api/auth/me/`
  - `refreshToken()` — calls `/api/auth/token/refresh/`
- [ ] Create `AuthContext` (`src/context/AuthContext.tsx`)
  - State: `user`, `isAuthenticated`, `isLoading`
  - On mount: call `getMe()` to check if user has valid cookie
  - Provides: `login()`, `register()`, `logout()`, `user`, `isAuthenticated`, `isLoading`
- [ ] Create `ProtectedRoute` component (`src/components/common/ProtectedRoute.tsx`)
  - Renders `<Outlet />` if authenticated
  - Redirects to `/login` if not (with return URL)
- [ ] Setup React Router v7 in `App.tsx`
  - Public routes: `/`, `/shop`, `/products/:id`, `/login`, `/register`
  - Protected routes: `/chat`, `/cart`, `/wishlist`, `/orders`, `/profile`
  - Login/Register redirect to `/` if already authenticated
- [ ] Verify: protected route redirects when not logged in

## Key Decisions
- `withCredentials: true` on Axios (required for HttpOnly cookies)
- AuthContext calls `/api/auth/me/` on mount to hydrate auth state
- Axios interceptor handles silent token refresh on 401
- React Router v7 (latest stable)
