# 2.4 — Login & Register UI Pages

**What to build:** Login and Register page components with form validation, error handling, and the complete end-to-end auth flow working visually.

**Blocked by:** 2.3 — React Auth Plumbing

**Status:** ready

## Deliverables
- [ ] Login page (`src/pages/Login.tsx`)
  - Email + Password fields
  - Submit calls `login()` from AuthContext
  - Error display (invalid credentials, network errors)
  - Link to Register page
  - Redirects to home (or return URL) on success
- [ ] Register page (`src/pages/Register.tsx`)
  - Email + Password + Confirm Password fields
  - Frontend validation: passwords match, email format, min length
  - Submit calls `register()` from AuthContext
  - Error display (email already exists, validation errors)
  - Link to Login page
  - Auto-login on success → redirect to home
- [ ] Styling matches design system (editorial, Playfair Display headings, Inter body)
- [ ] Loading states on submit buttons
- [ ] Verify: full flow works — register → auto-login → visit protected page → logout → redirect to login

## Key Decisions
- Password confirm is frontend-only validation
- Use existing designs from `designs/page-login` and `designs/page-register` as reference
- Match the editorial aesthetic (Decision #12)
