# 3.2 — Products REST API

**What to build:** A read-only Products API that returns a cursor-paginated list of products (12 per page) and a single product by slug. Public access (no auth required). Verifiable by hitting the endpoints in a browser or with curl.

**Blocked by:** 3.1 — Django Product Models + Seed Data

**Status:** ready-for-agent

- [ ] `CategorySerializer` (id, name, slug)
- [ ] `ProductSerializer` with nested category (id, name, slug, description, price, discount_price, brand, sizes, colors, gender, stock, rating, category)
- [ ] Read-only `ProductViewSet` with `list` and `retrieve` actions
- [ ] Cursor pagination configured at 12 items per page (ordered by `-created_at` or `id`)
- [ ] `AllowAny` permission — browsing products is public
- [ ] URL routing: `/api/products/` (list) and `/api/products/<slug>/` (detail)
- [ ] Verify: curl paginated list, follow cursor to next page, retrieve single product by slug

## Key Decisions
- Cursor pagination over offset — handles real-time data insertion without page drift, stronger interview answer
- Page size of 12 — industry standard, divides evenly into 2/3/4-column responsive grids
- No filters in this ticket — filters (price, size, color, brand, category) come in ticket 04
- Slug-based lookup over ID — user-friendly URLs
