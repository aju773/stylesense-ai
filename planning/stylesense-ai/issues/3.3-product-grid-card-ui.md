# 3.3 — React Product Grid + Card UI

**What to build:** Visiting `/products` shows a responsive magazine-style grid of product cards with a "Load more" button for cursor-paginated infinite loading. Cards show a styled fallback image area, product name, brand, price (with discount strikethrough when applicable), and a subtle rating.

**Blocked by:** 3.2 — Products REST API

**Status:** ready-for-agent

- [ ] TanStack Query `useProducts` hook using `useInfiniteQuery` for cursor pagination
- [ ] `ProductGrid` component — responsive grid layout: 2 cols (mobile) → 3 cols (tablet) → 4 cols (desktop)
- [ ] `ProductCard` component — minimal editorial style: fallback image area (styled gradient/placeholder), product name, brand, price with discount strikethrough, subtle rating
- [ ] "Load more" button wired to fetch next cursor page
- [ ] Cards are clickable `<Link>` elements navigating to `/products/:slug`
- [ ] `/products` route registered in React Router
- [ ] Verify: grid renders seeded products, responsive at all breakpoints, "Load more" fetches next page

## Key Decisions
- Minimal+ card design — editorial high-fashion aesthetic, no color swatches or sizes on card (those go on detail page)
- Styled fallback instead of placeholder images — gradient with category name or brand initial until real images are added
- 2→3→4 responsive columns — industry standard for fashion catalogs
- TanStack Query's `useInfiniteQuery` — natural fit for cursor pagination + "Load more" pattern
