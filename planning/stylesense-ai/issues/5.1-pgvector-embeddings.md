## Key Decisions
- Docker image `pgvector/pgvector:pg16` — pre-built, no custom Dockerfile needed
- 768 dimensions — matches Gemini `text-embedding-004` default output
- HNSW index over IVFFlat — no training step required, better recall
- Embedding text = `"{name}. {description}"` — captures both identity and details for semantic search
