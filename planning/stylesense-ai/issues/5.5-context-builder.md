# 5.5 — Context Builder (Vector Search)

**What to build:** A service that takes a user's chat message, embeds it using Gemini `text-embedding-004`, performs cosine similarity search against product vectors in pgvector, and returns the top matching products formatted as a context string ready to inject into the AI system prompt.

**Blocked by:** 5.1 — pgvector Docker + Product Embeddings

**Status:** ready-for-agent

- [ ] Create `apps/chat/services/context_builder.py`
- [ ] Async method: embed user message using `GeminiEmbeddingService` (from 5.1)
- [ ] Query products by cosine similarity using `CosineDistance` from `pgvector.django`, return top 5
- [ ] Format matched products as a structured context string (name, brand, price, sizes, colors, description) suitable for system prompt injection
- [ ] Handle edge case: no products have embeddings yet → fall back to empty context with graceful message
- [ ] Verify: call context builder with "red summer dress" → returns relevant products from the 50 seeded items

## Key Decisions
- Top 5 products — enough context without bloating the prompt
- Embedding service is reused from `apps/products/services/` (created in 5.1) — no duplication
- Context string format is plain text, not JSON — the AI reads natural language better than raw JSON for recommendation tasks
- Async embedding call — matches the async-first architecture decision
