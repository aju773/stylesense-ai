# 6.1 — Django Channels + WebSocket Plumbing

**What to build:** A WebSocket endpoint at `ws/chat/` that accepts authenticated connections and echoes messages back. This proves the full Channels stack end-to-end: `daphne` as the ASGI server, `channels_redis` as the channel layer backed by the existing Redis container, ASGI routing via `ProtocolTypeRouter` + `URLRouter`, and a custom cookie-based JWT auth middleware that reads the `access_token` cookie from the handshake headers to set `scope["user"]`.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Install `channels`, `channels_redis`, and `daphne` via `uv`
- [ ] Add `daphne` and `channels` to `INSTALLED_APPS`, configure `CHANNEL_LAYERS` pointing at Redis on `localhost:6380`
- [ ] Update `core/asgi.py` with `ProtocolTypeRouter` splitting HTTP and WebSocket traffic
- [ ] Create cookie-based JWT auth middleware for Channels (reads `access_token` cookie, decodes JWT, sets `scope["user"]`)
- [ ] Create a basic `ChatConsumer` (async `JsonWebSocketConsumer`) at `ws/chat/` that accepts authenticated connections and echoes messages back, rejects anonymous
- [ ] Verify with a WebSocket client tool (websocat or browser console) that auth + echo works
