# 6.2 — Streaming Provider + ChatService

**What to build:** Add streaming capability to the AI provider stack. Both Gemini and Groq providers gain a `generate_completion_stream` async generator method that yields tokens as they arrive. The orchestrator gets a matching streaming method with the same fallback behavior (try Gemini, fall back to Groq on transient errors). ChatService gains `send_message_stream` — an async generator that handles the full chat turn (save user message, build context, stream AI response, save complete AI message at the end). Verifiable by calling `send_message_stream` from a Django shell or management command and watching tokens print to stdout.

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Add `generate_completion_stream` abstract method to `BaseAIProvider` (async generator yielding `str` chunks)
- [ ] Implement `generate_completion_stream` on `GeminiProvider` using `client.aio.models.generate_content_stream()`
- [ ] Implement `generate_completion_stream` on `GroqProvider` using `stream=True` on `chat.completions.create()`
- [ ] Add `generate_completion_stream` to `AIProviderOrchestrator` with same transient/permanent fallback logic
- [ ] Add `send_message_stream` async generator to `ChatService` — yields tokens during streaming, saves the concatenated AI response as a `ChatMessage` after the stream ends
