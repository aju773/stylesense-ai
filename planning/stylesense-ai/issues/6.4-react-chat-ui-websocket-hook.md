# 6.4 — React Chat UI + WebSocket Hook

**What to build:** The complete chat page replacing the current stub. A custom `useChat` hook manages the native WebSocket connection (connect, auto-reconnect, parse the JSON protocol, expose state). The page has a conversation sidebar listing past conversations via the existing REST endpoint (TanStack Query), and a chat window with styled chat bubbles (user vs assistant), a typing indicator shown between `stream_start` and the first `token`, markdown rendering in assistant bubbles (`react-markdown`), and an input that disables while streaming. Clicking a sidebar conversation loads its history via `GET /api/chat/conversations/<id>/messages/`. End-to-end demoable: user sends a message, sees "thinking" indicator, tokens stream in live, full conversation persisted.
