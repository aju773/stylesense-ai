# 7.1 — Product Markers in the AI Contract

**What to build:** Teach the AI to cite catalog products with machine-readable markers so structured product data can survive a plain-text token stream. The context builder includes each product's primary key in the injected catalog, and the system prompt defines a strict `[[product:<id>]]` citation contract. Chosen over tool/function calling because the provider interface yields `str` — markers keep `AsyncGenerator[str]`, streaming, and the Gemini→Groq fallback all untouched. Chosen over JSON-mode output because that would kill token streaming outright.
