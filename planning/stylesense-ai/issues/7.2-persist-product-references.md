# 7.2 — Persist Product References

**What to build:** Turn the markers in a saved AI reply into real database relations, so history renders the same cards the live stream did. `ChatMessage` gains a `products` M2M; `ChatService` parses markers after saving the assistant message and links only ids that match active catalog rows — which also discards hallucinated ids for free. `ProductCardSerializer` gives a compact card payload nested into `ChatMessageSerializer`, ordered by first mention in the message body.
