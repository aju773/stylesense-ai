# 8.2 — Cart REST API

**What to build:** Four authenticated endpoints over the bag, with a service layer (`apps/cart/services/cart_service.py`) owning every business rule and every rupee of arithmetic. The client never computes or sends money: it posts a product id and a variant, and the server answers with the whole recomputed bag. Item routes scope their lookup by `cart__user=request.user` rather than checking ownership after fetching — someone else's item id is then indistinguishable from a nonexistent one, so both give 404 and neither leaks what other carts hold.

**Blocked by:** 8.1 — Cart Models
