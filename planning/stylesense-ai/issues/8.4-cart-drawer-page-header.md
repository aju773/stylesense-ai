# 8.4 — Cart Drawer, Cart Page, and Site Header

**What to build:** The cart UI, plus the global chrome it needs to exist in. The app had no header or nav anywhere — `Products.tsx` had zero navigation links — so the badge and drawer trigger had nowhere to live. This slice builds a minimal `SiteHeader` from the cart design and applies it as a layout route, which also gives every later epic (wishlist, orders, profile) somewhere to hang its links.

**Blocked by:** 8.3 — Cart Data Layer

**Status:** done

- [x] `SiteHeader` — wordmark, Home/Shop/AI Stylist nav, bag button with live count badge, login/logout. Nav renders inline on desktop and as a second row on mobile rather than being hidden, so small screens keep their navigation
- [x] `AppLayout` — layout route holding header + drawer + `<Outlet/>`; login and register stay outside it
- [x] `CartDrawer` — right slide-in with scrim, Escape to close, body scroll lock restored on unmount, empty state, footer total
- [x] `CartLineItem` — thumbnail (gradient fallback), variant meta, quantity stepper, remove; `compact` variant for the drawer. Disables its controls while `item.id < 0` (an optimistic placeholder has no server row to PATCH yet)
- [x] `CartSummary` — subtotal / discount / shipping / total, straight from the server's numbers
- [x] `pages/Cart.tsx` — full page, sticky summary column, empty state
- [x] `App.tsx` — `/cart` route inside `ProtectedRoute`, all pages wrapped in `AppLayout`, `CartUIProvider` mounted
- [x] `ProductDetail` — the dead "Add to Bag" button now adds, guards on size/color selection, redirects anonymous users to `/login` with `from`, surfaces server `detail` errors, and opens the drawer on success

## Verified in the browser

- Add to Bag with nothing selected → "Please select a size."
- Add M/Navy → drawer opens, line shows ₹2,961 paid / ₹4,102 list / Save ₹1,141, badge → 1
- Quantity `+` → badge, drawer, and totals all move together off the one cache
- **Rollback:** deleted the row from the DB behind the UI, then clicked `+` → quantity went 2 → 3 optimistically, server 404'd, UI restored to 2
- Three lines incl. the same jacket in M and L as separate lines → subtotal ₹23,163, discount ₹3,423, total ₹19,740 (matches by hand)
- Remove → badge 6 → 3 within one frame, totals recomputed correctly
- Logged out → badge 0, no `/api/cart/` request at all, Add to Bag redirects to `/login`
- Logged in as a second user → badge 0, not the previous user's 3
- Drawer opens from the header, closes on Escape and on scrim click, body scroll restored
- Mobile 375px: no horizontal overflow, drawer full-width, mobile nav row visible
