# 9.1 — Wishlist Model

**What to build:** A new `apps.wishlist` holding saved products. One flat `WishlistItem` — there is deliberately no parent `Wishlist` row the way there is a `Cart`: a cart owns totals and per-bag state, a wishlist owns nothing but its set of items, so a parent row would be a join with no columns worth reading. Uniqueness is `(user, product)`, not `(user, product, size, color)` — you save a *product*, not a variant; the size decision belongs at add-to-bag time, where a picker already exists.

The `source` field (`manual` / `ai`) is what the page's two tabs read. An item is `ai` when it was hearted off an AI recommendation card in chat, `manual` everywhere else — the AI never writes to the wishlist on its own.
