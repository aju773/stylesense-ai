# 9.3 — Wishlist Data Layer + Heart Toggle

**What to build:** TanStack Query hooks over the wishlist endpoints, plus the `SaveButton` heart that uses them — dropped onto the catalog grid, the product detail page, and the AI chat product strip (where it saves with `source: "ai"`).

Follows the cart's optimistic pattern exactly: `onMutate` flips the heart, the snapshot rolls it back on error. A heart that waits ~200ms for the server before filling reads as broken.

**Blocked by:** 9.2 — Wishlist REST API

**Status:** done

- [x] `api/wishlist.ts` — types + `fetchWishlist` / `toggleWishlist` / `removeWishlistItem`
- [x] `hooks/useWishlist.ts` — one `["wishlist"]` cache, `useIsSaved(productId)`, optimistic toggle with rollback
- [x] Cache purged on login/register/logout in `AuthContext`, same as the cart
- [x] `SaveButton` — filled/outline heart, anonymous click redirects to `/login` with `from`
- [x] Wired into `ProductCard`, `ProductDetail`, `ChatProductStrip` (the last with `source: "ai"`)
- [x] `ProductCard` and the chat mini-card restructured so the heart is a *sibling* of the link, not a child — a `<button>` inside an `<a>` is invalid HTML and makes every save click fight the anchor's navigation
- [x] `useRemoveWishlistItem` for 9.4's page, which unsaves by row id rather than toggling

## Verified in the browser

- Heart while logged out → `/login`, and signing in lands back on `/shop`
- Two saves from the catalog grid → both hearts fill, `aria-pressed="true"`, page does not navigate
- Opening a saved product's detail page shows **Saved to Wishlist** — one `["wishlist"]` cache, so every surface agrees without any sync code
- Chat: asked for denim jackets, hearted a returned card → DB records `source: ai` for that row and `manual` for the two catalog saves
- **Rollback:** deactivated a product behind the UI, then hearted it — `MutationObserver` caught `pressed=true` at **2ms**, the server's 400 at **28ms**, and the heart reverted. (Sampling at 50ms missed it entirely; the optimistic window on localhost is ~26ms)
- Logged in as a second user → every heart unfilled, not the first user's three saves
- Heart is 32px, inset 8px from the image's top-right, inside the image bounds; no horizontal overflow at 1280px or 375px
- No JS exceptions in the console — only the deliberate 400s and the logged-out 401s
