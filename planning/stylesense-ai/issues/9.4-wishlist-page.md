# 9.4 — Wishlist Page

**What to build:** `/wishlist` per the design — item count in the heading, "All Saved" / "AI Picks" tabs, a 4-up grid of saved cards with the heart as an unsave control, and the out-of-stock treatment the design specifies.

**Blocked by:** 9.3 — Wishlist Data Layer

**Status:** done

- [x] `pages/Wishlist.tsx` replacing the `<h1>` stub, mounted on the existing protected route
- [x] Tabs filter the one cached list client-side — the whole wishlist is already loaded, so a per-tab request would be a round-trip to hide rows the browser is holding
- [x] `WishlistCard` — image/gradient, brand, name, price with markdown, added date, unsave heart, "Move to Bag"
- [x] Out-of-stock cards dimmed with the badge, CTA suppressed
- [x] "Move to Bag" routes to the product page rather than adding blind — every product in the catalog has sizes and colors, so a direct add would have to invent a variant
- [x] Empty states: nothing saved at all, and nothing in the AI tab
- [x] Wishlist link in `SiteHeader` for authenticated users
- [x] `✦ AI Pick` label on AI-sourced cards — in All Saved, it is the only thing that says where a save came from
- [x] "Move to Bag" reveal keyed on `@media (hover: hover)`, not a breakpoint
- [x] Failed mutations reconcile with the server, not just roll back

## Verified in the browser

- Empty wishlist → "Nothing saved yet" + Browse the Catalog; `Wishlist` link visible in the header for authenticated users only
- 3 saves → `Wishlist (3 items)`, AI-sourced card carries `✦ AI Pick`, markdown prices show list price struck through
- **Out of stock:** card dimmed, badge shown, and the Move to Bag CTA suppressed entirely rather than rendered dead
- `AI Picks` tab → 1 of 3 cards, `aria-pressed` moves with the tab; unsaving the last AI pick drops straight to the AI empty state with its Ask the AI Stylist link
- Unsave persists — the row is gone from the DB, and the heading recounts to `(2 items)`
- **Rollback + reconcile:** deleted a row behind the UI, then unsaved it — card left the grid at **17ms**, the 404 restored it at **38ms**, and the refetch removed it again at **61ms**, landing on the server's truth. Rollback alone would have left a card for a row that no longer exists
- Move to Bag → `/products/<slug>` with the real size picker; the product page shows **Saved to Wishlist** off the same cache
- **Touch:** at 375px `(hover: hover)` is false and the CTA renders at full opacity; at desktop width it sits at `translate: 0 100%`, opacity 0 until hover. One column at 375px, no horizontal overflow
- Catalog left as seeded — the product zeroed to test the out-of-stock state was restored to its seed value of 63
